# TYT — موقع المنيو (نفس تصميم الموقع الأساسي)

موقع مستقل، صفحة واحدة، بنفس هوية الموقع الأساسي بالظبط (نفس الألوان
البنفسجي/الدهبي الغامقة، نفس الخطوط، نفس شكل كروت الأصناف والتابات
والمودال) — بس من غير الهيرو/الأباوت/الجاليري/العروض، عشان يكون مخصص
للمنيو بس ويتفتح بسرعة من QR على الطرابيزة.

## إيه اللي اتغيّر عن النسخة اللي فاتت
- الشكل بقى **مطابق للموقع الأساسي 100%** (نفس `css/style.css` و`js/i18n.js` منسوخين حرفيًا من الموقع الأساسي).
- **17 قسم و133 صنف** — اتشالت أقسام: Shisha، Suhoor، Food (أكل خفيف)، Cigarettes، PlayStation، Birthday، Sandwiches.
- بحث فوري + تابات تصنيفات (بينسحبوا بالماوس/باللمس) + مودال "نظرة سريعة" على أي صنف (تظهر صورته واسمه ووصفه وسعره) + نظام **مفضلة** بسيط (قلب على أي صنف، بيتحفظ على نفس الجهاز/المتصفح بس، من غير حساب) — كل ده منسوخ بنفس سلوك الموقع الأساسي.
- زرار AR/EN فوق بيترجم كل حاجة زي الموقع الأساسي بالظبط (أسماء الأصناف والأوصاف كمان، مش بس نصوص الواجهة).

## تشغيله محليًا
```bash
python3 -m http.server 8080
# افتح http://localhost:8080
```

## رفعه أونلاين (Vercel أو Netlify)
1. اسحب مجلد `tyt-menu` على app.netlify.com/drop، أو ارفعه كـ repo على GitHub وربطه بـ Vercel.
2. مفيش build command — الموقع static بالكامل.
3. الرابط اللي هتاخده بعد النشر (زي `tyt-menu.vercel.app`) هو اللي يتحط في QR كود يتطبع على الطرابيزة/الكارت.

## تعديل المنيو
البيانات في `js/menu-data.js` — نفس الملف بتاع الموقع الأساسي، منسوخ منه مباشرة.
الموقعين مش مربوطين ببعض حاليًا (مفيش قاعدة بيانات مشتركة)، فلو عدّلت
المنيو في الموقع الأساسي، انسخ نفس الملف هنا تاني عشان يفضلوا متطابقين.

أي `note` داخلي في `menu-data.js` (ملاحظات تحرير للمالك بس) بيتجاهل تلقائيًا
ومبيظهرش للعميل — بالظبط زي الموقع الأساسي.

## الملفات
```
tyt-menu/
├── index.html         → هيكل الصفحة (نافبار + قسم المنيو + مودال + فوتر مصغر)
├── css/style.css        → نفس ملف الموقع الأساسي بالحرف
├── js/
│   ├── menu-data.js       → بيانات المنيو (نفس الموقع الأساسي)
│   ├── i18n.js             → الترجمة AR/EN (نفس الموقع الأساسي)
│   └── menu-app.js          → منطق العرض/البحث/التابات/المودال/المفضلة (نسخة مبسطة من main.js، من غير Firebase/العروض)
└── images/                  → اللوجو + صور كل الأصناف
```
